# Fin and Nance

Marketing site for the *Fin and Nance* children's book series on financial literacy. Vue 3 + Vite + Tailwind CSS.

## Setup

Requires Node.js 20.19+ (or 22.12+).

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
```

## Stack

- Vue 3 (Composition API), Vue Router, Pinia
- Vite
- Tailwind CSS

## Structure

```text
src/
├── components/    # Header, Footer, BookCard
├── views/         # LandingView, AboutView, BooksView
├── router/        # Route definitions
├── stores/        # Theme store (dark mode)
├── assets/css/    # Global styles
├── App.vue
└── main.js
```
